# PUNE 40 · AI for Urban Economic Transformation

This folder is ready to publish with GitHub Pages. `index.html` is the complete self-contained showcase.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. After GitHub Pages finishes building, share the Pages URL shown in Settings → Pages.

Anyone who can access the public repository and its Pages site can view this showcase.
